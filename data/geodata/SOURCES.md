# Nauru geodata sources

This directory is generated by `.github/workflows/geodata-import.yml`.

- `nauru.osm.gz`: OpenStreetMap data for bounding box `166.88,-0.59,167.02,-0.45`, downloaded from the OpenStreetMap API. OpenStreetMap data is © OpenStreetMap contributors and licensed under the Open Data Commons Open Database License (ODbL): https://www.openstreetmap.org/copyright
- `nauru-dem-30m.bin`: a Nauru crop from the 1-arc-second SRTM tile `S01E166`, distributed through the AWS Terrain Tiles dataset. SRTM elevation data was produced by NASA/NGA and is public domain in the United States.

The game must display OpenStreetMap attribution anywhere derived OSM geometry is used. Google Maps, Google Earth, and Street View imagery are not used.
